基于C语言开发的开关电源数字控制算法库，提供电源拓扑建模、PID闭环控制及PWM波形生成等核心功能。

# UPS-1KVA-HF 固件工程

1KVA 高频在线互动式 UPS（不间断电源）完整固件，目标平台 **STM32F103RCT6**（72MHz / 48KB RAM / 256KB Flash），基于 STM32CubeF1 HAL 库。

---

## 1. 整机规格

| 项目 | 参数 |
|---|---|
| 额定容量 | 1000VA / 800W (PF=0.8) |
| 输出电压 | 220VAC ±5%（纯正弦波，SPWM） |
| 输出频率 | 50Hz ±0.5Hz（电池模式） |
| 电池组   | 24VDC（2 × 12V/9Ah 铅酸串联） |
| 直流母线 | 380VDC（320V 欠压 / 420V 过压保护） |
| 市电窗口 | 110-300VAC，45-65Hz |
| 转换时间 | <10ms（市电→电池，逆变热备锁相） |
| 充电方式 | 三段式：恒流 2A → 恒压 28.8V → 浮充 27.2V |
| 通信接口 | UART 2400 8N1，兼容 Megatec Q1 协议 |
| 保护 | 过载反时限、短路（硬件 <50μs）、过温、母线过/欠压、电池过压、输出电压异常 |

## 2. 功率拓扑

```
市电输入 ──┬──[输入继电器]──[旁路继电器]──[输出继电器]── 输出 220VAC
           │
           └── 辅助电源 ──> 控制板供电
           
电池 24VDC ──[TIM2 推挽升压 50kHz]──> 380VDC 母线
                                        │
                        [TIM1 全桥 SPWM 20kHz 单极性调制]
                                        │
                              LC 滤波 ──> 输出 (经输出继电器)
                              
380VDC 母线 ──[TIM3 BUCK 50kHz]──> 电池充电 (三段式)
```

**工作模式**：市电正常时旁路直通输出 + 充电，逆变热备并与市电锁相同相；市电异常时 20ms 消抖确认后断旁路，逆变无缝接管；过载等可恢复故障转静态旁路。

## 4. 软件架构

### 4.1 任务调度（协作式，SysTick 1ms 驱动）

| 周期 | 任务 |
|---|---|
| 1ms | 采样滤波、短路保护确认 |
| 10ms | RMS/功率计算、市电判定、逆变 RMS 环、母线环、充电环、状态机、按键 |
| 50ms | 通信协议解析 |
| 100ms | 充电阶段切换、SOC/后备时间、电池自检 |
| 250ms | LED / 蜂鸣器刷新 |

### 4.2 中断优先级

| 优先级 | 中断 | 用途 |
|---|---|---|
| 0 | TIM1_BRK | 硬件过流刹车（BKIN 即时封锁 PWM） |
| 0 | TIM1_UP (20kHz) | SPWM 波形逐点生成 + 瞬时电压环 |
| 1 | EXTI0 | 市电过零捕获（测频 + 锁相） |
| 2 | USART3_RX | 通信接收 |
| 3 | SysTick | 系统节拍 |

### 4.3 状态机

```
POWER_ON ──> STANDBY ──> LINE_MODE <──> BATTERY_MODE
                ▲            │                │
                │            └──> BYPASS      │ (电池耗尽)
                │                  │          ▼
                └──── FAULT <──────┴──>   SHUTDOWN
              (故障锁存, 按键复位)      (市电恢复自动重启)
```

### 4.4 逆变控制（双环）

- **外环（10ms）**：输出电压 RMS 闭环，PI 调节调制深度，稳压 220V
- **内环（20kHz）**：瞬时值比例修正 + 波形前馈，抑制带载失真
- **锁相**：市电过零触发相位修正，每周期最多 ±2 步（±3.6°）平滑跟踪，保证无缝切换
- **软启动**：3s 调制深度线性爬升，防冲击

### 4.5 保护策略

过载反时限曲线：

| 负载率 | 动作 |
|---|---|
| >105% | 蜂鸣器告警，不关机 |
| >125% | 30s 后故障 |
| >150% | 1s 后故障 |
| >200% | 100ms 后故障 |
| 短路 | 硬件比较器 <50μs 封锁 PWM，软件 3ms 确认锁存 |

## 5. 通信协议（USART3, 2400 8N1）

| 命令 | 应答 | 说明 |
|---|---|---|
| `Q1` | `(MMM.M NNN.N PPP.P QQQ RR.R S.SS TT.T bbbbbbbb` | Megatec 标准状态帧（市电V/输出V/负载%/频率/电池V/温度/状态位），兼容 NUT、WinPower |
| `QF` | `(F:XXXXXXXX` | 故障位图（hex） |
| `QI` | `(#UPS-1KVA-HF FW1.0.0 ...` | 机型信息 |
| `QS` | `(SSS MMMM STATE` | SOC%、预估后备分钟、状态名 |
| `F` | `(F 220 050 024 027.2` | 额定参数 |
| `TL` | `(ACK` | 触发 10s 电池自检 |
| `S0`/`S1` | `(ACK` | 蜂鸣器 恢复/静音 |

```bash
python tools/ups_monitor.py --port COM3 --baud 2400 --interval 2
```

## 6. 移植指南

1. **修改参数**：`Inc/ups_config.h` 集中了全部规格、阈值、采样系数（`SCALE_*`）、引脚定义——绝大多数适配只改这一个文件
2. **BSP 层**：`Src/bsp.c` 基于 HAL 实现，换 MCU 时只需重写 BSP 接口（函数签名在 `Inc/bsp.h`），控制逻辑零改动
3. **引脚冲突已处理**：TIM2 部分重映射（PA15/PB3 推挽升压）、TIM3 完全重映射（PC6 充电），并禁用了 JTAG 释放引脚
4. **采样系数校准**：`SCALE_*` 为标称分压比，量产前需接标准源逐通道校准（建议后续改为 EEPROM 校准参数）

## 7. 构建

1. 用 STM32CubeMX 建立 F103RCT6 工程（或直接建立 Makefile 工程），加入 STM32CubeF1 HAL 库与 CMSIS 启动文件
2. 将 `Inc/` 加入头文件路径，`Src/*.c` 加入编译
3. 编译选项建议：`-O2 -Wall -Wextra -ffunction-sections -fdata-sections -std=c11`
4. 注意：工程使用 `sinf`，需链接数学库（`-lm`）

## 8. 调试流程（务必按顺序）

> ⚠️ 电力电子产品存在高压危险，禁止跳过任何一步直接上 220V 市电。

1. **控制板单独上电**：不推功率管，确认采样值合理、状态机进入 STANDBY、串口 Q1 有应答
2. **低压直流模拟电池**：用可调直流电源（限流）代替电池，验证升压环建立母线
3. **隔离变压器供电**：市电经隔离变压器接入，验证过零捕获、锁相、模式切换
4. **小负载验证**：100W 灯泡负载，示波器观察输出波形 THD、切换瞬间波形连续性
5. **逐级加载**：25% → 50% → 100% → 110% 验证过载告警与反时限动作
6. **保护实测**：短路保护动作时间（<50μs）、过温降额、电池低电关机、市电恢复自启动
7. **老化测试**：满载 4 小时以上，监测温度与波形稳定性

## 9. 已知限制与后续方向

- SOC 估算为开路电压 + 安时积分融合，精度受电池老化影响，可升级为库仑计芯片（如 BQ34Z100）
- 未实现 EEPROM 参数存储（校准值、运行日志），预留了 `FAULT_EEPROM` 故障位
- 单机版本，未含并机均流逻辑
- 瞬时电压内环为比例控制，对非线性负载（整流性负载）可升级为重复控制或 PR 控制
